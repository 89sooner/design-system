# Conductor 경쟁력 평가 리포트

> 작성일: 2026-10-13 | 기준 버전: 0.7.0 (tokens·css·react) | 범위: 시중 주요 디자인 시스템(MUI, Ant Design, Carbon, Polaris, Primer, Radix Themes, shadcn/ui, Vercel Geist)과의 비교

## 결론

- **품질과 엄격성:** "운영 도구용, 중소 규모, 품질 우선"이라는 범주에서는 상위권 시스템과 견줄 수 있다. 대비 게이트, 런타임 측정의 일치, 공급망 보증, 에이전트 판독용 문서는 일부 대형 시스템보다 앞선다.
- **시장 순위:** 상위권이 아니다. 순위를 정하는 채택, 컴포넌트 폭, 디자이너 도구, 생태계가 비어 있다.

## 상위권과 견줄 만한 영역

| 항목 | Conductor | 비교 |
| --- | --- | --- |
| 대비 검증 | 120쌍 / 240검사를 빌드 게이트로 강제한다. 같은 계산을 런타임 함수(`contrastRatio`, 0.7.0)로 공개한다 | 대부분은 문서 권장에 그친다. 게이트로 막는 곳은 Carbon·Polaris 정도다 |
| 공급망 | npm provenance, OIDC 게시, audit 게이트, API 리포트로 파괴 변경을 감지한다 | MUI·Radix 수준. 중소 시스템 대부분보다 엄격하다 |
| 접근성 | 동작을 Radix에 위임한다. axe를 4폭 × 2테마로 검사하고, 키보드 지침 47종을 둔다 | Radix Themes·shadcn과 같은 기반이다 |
| AI 에이전트 대응 | DESIGN.md, llms.txt, 컴포넌트별 Markdown | Vercel Geist 등 최신 흐름과 같은 선이다 |
| 추적성 | 요구사항 → 코드 → 시험이 ID로 연결되고, 모든 변경이 CR로 기록된다 | 오픈소스 시스템에서는 드물다 |

## 상위권에 못 미치는 영역

1. **채택과 생태계:** 사용자, 기여자, 실제 제품 적용 사례가 사실상 없다.
2. **컴포넌트 폭:** 47개다. 상위권은 100개 이상이며 날짜 선택기, 데이터 그리드, 토스트, 커맨드 팔레트 같은 고급 컴포넌트를 갖춘다.
3. **디자이너 도구:** Figma 라이브러리와 Code Connect가 없다.
4. **국제화:** RTL, 로캘 서식, 다국어 문서가 없다. 문서 사이트는 영어와 한국어가 섞여 있다(작업 공간·블록 예제는 한국어). react 패키지의 CR-041 컴포넌트(워크벤치·관계 그래프·운영 상태)는 한국어 문구를 직접 품고 있다.
5. **문서 기능:** 검색, 버전별 문서, 편집 가능한 코드 플레이그라운드가 없다.
6. **시각 정체성:** 다크 우선의 운영 도구 미감 하나뿐이다. 브랜드 확장은 테마 플레이그라운드(W-031)로 첫걸음을 뗐다.
7. **검증 이력:** 0.x 버전이고, 실사용에서 드러날 엣지 케이스를 아직 겪지 않았다.
