# Conductor Design System SRS 작성 워크플로

> 상태: review | 버전: v0.2 | 갱신일: 2026-07-10

## 1. 목적

이 문서는 Conductor Design System의 요구사항을 후보 기능에서 최종 SRS까지 정제하는 절차를 정의한다.

## 2. 단계

1. 분석 범위 정의
2. 소스 수집 및 분석 기준 수립
3. 기능 인벤토리 작성
4. 기능 클러스터링 및 정보 구조 정리
5. 도메인 용어 정의 (`glossary.md`)
6. 사용자 시나리오 및 업무 흐름 도출
7. 구현/운영 대응성 검토
8. 비기능 요구사항 및 제약 정의
9. SRS 초안 작성
10. 검토, 우선순위화, 확정(baseline)

## 3. 기능 분석 필드

- 기능 ID
- 사용자 목표
- 출처/근거
- 진입 화면 또는 트리거
- 주요 액션
- 시스템 반응
- 예외 상황
- 데이터 모델 영향
- 권한 및 감사 요구
- 실현 방식
- 릴리스 후보

## 4. 추적 구조

소스 문서 ID -> 기능 ID -> 시나리오 ID -> 요구사항 ID -> 화면 ID -> WP ID -> QA 항목 -> 코드/테스트

## 5. SRS 작성 원칙

- 기능 요구사항은 고유 요구사항 ID와 전체 블록(출처, 수용 기준, 검증 방법, 관련 ID)을 가진다.
- 요구사항 문장은 EARS 패턴(상시/이벤트/상태/예외/선택) 중 하나를 따른다.
- 검증 가능한 문장으로 작성한다. 빠르게/쉽게/적절히 같은 비계량 표현은 수치로 대체한다.
- UI 설명과 시스템 행위를 구분한다. 배치·문구는 파생 UI 문서의 몫이다.
- 제외 범위와 조건부 범위를 명시한다.
- 미확정 사항은 가정 또는 오픈 결정(`OD-###`)으로 남기고 임의로 확정하지 않는다.

## 6. 이 제품에 실제로 적용된 절차 (2026-07-10)

Conductor의 요구사항은 신규 기획이 아니라 **기존 제품의 시각 언어 추출**에서 도출되었다. 따라서 2절의 절차가 다음과 같이 구체화되었다.

| 단계 | 이 제품에서의 실행 | 산출 |
| --- | --- | --- |
| 1 분석 범위 정의 | `agent-ai-platform/packages/web`의 스타일 계층으로 범위를 한정. 도메인 컴포넌트는 제외 대상으로 사전 선언 | `feature.md` 3절 제외 후보 |
| 2 소스 수집 | `packages/web/src/styles/tokens.css`(94줄)와 `app.css`(1324줄) 전문 실측. 별도 디자인 산출물(Figma)은 존재하지 않음 | 출처 표기 `SRC-AAP` |
| 3 기능 인벤토리 | 소스에서 관찰된 시각 장치를 후보 기능으로 정규화. 소스에 없는 항목(3계층 토큰, 라이트 테마, 문서 사이트)은 `신규`로 명시 | `feature.md` 후보 44개 |
| 4 클러스터링 | TOK / THM / CSS / CMP / DOC / A11Y / DX / QA 8개 기능군 | `feature.md` 4절 |
| 5 용어 정의 | 소스의 암묵적 명명(`--status-*`, `--severity-*`)을 표준 용어로 승격하고 금지 동의어를 기록 | `glossary.md` |
| 6 시나리오 도출 | 소비자 개발자·관리자·접근성 검토자·코딩 에이전트 4개 역할로 SCN-001 ~ SCN-004 | `srs_final.md` 7절 |
| 7 구현 대응성 | 서버 런타임이 없다는 사실을 확인하고 아키텍처 문서군을 빌드 파이프라인·패키지 API·토큰 스키마·CI 잡으로 재해석 | CR-004 |
| 8 비기능 정의 | 번들 크기·대비율·빌드 시간·CI 시간을 실측 가능한 수치로 고정 | `srs_final.md` 12절 |
| 9 SRS 초안 | FR 48개를 전체 블록으로 작성 | `srs_final.md` 9절 |
| 10 검토·확정 | 소스 팔레트의 대비율을 WCAG 2.1 공식으로 실측해 미달 5건을 발견. OD-001로 사용자 결정을 받아 FR-THM-005를 신설(최종 49개) | CR-005 |

**이 절차에서 배운 것**: 기존 제품의 시각을 추출할 때, 소스 값을 무비판적으로 계승하면 결함까지 함께 계승한다. 값을 옮기기 전에 측정하는 단계(10단계)를 반드시 거친다. Conductor의 포커스 링 교정(FR-THM-005)은 이 단계에서만 발견될 수 있었다.
