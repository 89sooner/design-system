@h2 릴리스 과정에서 발견하고 고친 결함
@h3 DEV-018 / CR-025 — publish 성공 후 git tag 누락
@cmd Changesets는 npm publish 이후 annotated tag를 만들 때 git identity가 없으면 실패했지만 릴리스 전체를 실패시키지 않았다. 결과적으로 registry는 공개됐지만 git tag가 없었다.
@p 해소:
@path release job에 명시적 bot user.name/email 설정
@path scripts/check-release-tags.mjs 추가
@path 단순 ref 존재가 아니라 annotated tag object와 대상 commit을 local/remote에서 확인
@b 빠진 0.1.0 tags를 merge commit에 복구
@h3 DEV-019 / CR-026 — lucide peer 범위
@p semver 0.x에서 ^0.400.0은 <0.401.0이다. repo가 실제 사용하는 0.468을 허용하지 않는 계약이었다. React peer를 >=0.400.0 <2로 바꾸고 0.1.1 patch release에 포함했다.
@h3 DEV-021 / CR-028 — Node 22 axe animation flake
@path Node 22 main CI에서 light theme의 open Dialog가 간헐적으로 대비 실패했다. artifact의 foreground #dadee4는 원래 text가 아니라 #0c121c가 light surface #e4e8ed 위에 약 4.6% opacity로 합성된 중간 animation frame이었다. axe가 cdt-dialog-enter 도중 샘플링했다.
@p 해소:
@b render 뒤 한 번의 rAF로 Web Animations가 materialize되게 함
@b finite animations의 finished를 await
@b Spinner처럼 infinite animation은 대기 목록에서 제외하되 axe audit 대상에서는 제외하지 않음
@dec motion disable, arbitrary fixed sleep, axe rule disable은 사용하지 않음
@p 수정 뒤 browser a11y를 로컬에서 4회 연속 통과했다.
