@h2 Risks/gotchas
@cmd CI에 Playwright 브라우저 설치 단계가 없었다. pnpm 10이 lifecycle script를 차단해 pnpm install만으로는 브라우저가 없다 → WP-024가 심은 pnpm test:a11y는 첫 CI 실행부터 죽었을 것이다. 빈 캐시로 재현해 확인하고 pnpm exec playwright install --with-deps chromium을 추가했다. 검사를 쓰면 그 검사가 실제로 도는지까지 관찰하라(CR-009/CR-011과 같은 병).
@b chrome-launcher가 WSL에서 저장소를 오염시킨다. 프로필 경로를 Windows 형식(C:\..., \\wsl.localhost\...)으로 바꿔 리눅스 Chrome에 넘기고, Chrome이 그 문자열을 통째로 디렉터리 이름 삼아 cwd(저장소) ... + CDP 포트로 해소(chrome-launcher 제거). 외부 프로세스를 붙였으면 끝나고 git status로 트리를 본다.
