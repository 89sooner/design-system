## Decisions

- Light palette clones dark token metadata/key set and overrides only spec-derived values; this prevents key drift. Component-only light overrides are applied in `tokensForTheme` rather than duplicating all component tokens.
- Theme CSS keeps dark as `:root` fallback, uses explicit `:root[data-cdt-theme="light"]`, and applies OS-light only to `:root:not([data-cdt-theme])`. This preserves invalid attribute → dark.
- The React registry is explicit (component name/test file/SSR renderer). It is intentionally the extension point for later WPs; adding a public component requires adding it to the registry and its test file.
- `Card` warns in `useEffect`, not at module scope, so SSR remains safe. Nested interactive test intentionally suppresses React's DOM nesting diagnostic while asserting Conductor's warning.
- The root TS config now owns `jsx: react-jsx`; docs typecheck resolves `@conductor/react` source through workspace aliases and therefore needs JSX enabled too.
