## Decisions

- `queued`·`neutralEnd` StatusBadge는 채움이 아니라 점+텍스트 마커 형태다. 두 색의 usage/대비 제약을 지키면서 상태를 색에 의존하지 않게 한다.
- Table의 public root는 자체 가로 스크롤 `div`다. table name은 내부 `<table>`에도 전달하고 공통 계약용 aria/data prop은 root에도 유지한다.
- Timeline focus rule은 공통 reset focus ring을 대체하지 않는다. clipped parent 위로 올리는 `position: relative; z-index: var(--cdt-z-sticky)`만 추가한다.
- WP-014에 필요한 `timeline.*`, `codeBlock.*`, `kbd.*` component token은 UI component spec에 이미 열거된 semantic 매핑으로 추가했다. 새 색이나 요구사항을 만들지 않았다.
